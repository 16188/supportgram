Supportgram 客服组件测试

此页面用于演示 Supportgram 嵌入式客服组件。只需一行 <script> 标签，即可在任意网站中加入在线客服功能。

如何嵌入客服组件：

将下面这行代码添加到网站的 </body> 结束标签之前：

<script src="https://maitgsupportgram.888866.xyz/widget.js" data-key="你的公开密钥"></script>

参数说明：

  • src — 客服组件脚本地址，系统会使用该地址的域名作为 API 地址。
  • data-key — 公开业务密钥，用于识别会话所属的网站或商户。
本地测试：运行 npm start 后，可访问 http://localhost:3000/test.html。请将脚本中的 data-key 改为数据库里的有效公开密钥。
客服组件已加载！请查看页面右下角的客服图标，点击后即可开始会话。
